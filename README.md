# Mahmood Sufyan | Oracle APEX Portfolio

A bilingual, multi-page portfolio for Mahmood Sufyan. It includes a project index, three case studies, a career timeline, and a contact page. Golden Cloud includes a 60-second project walkthrough.

## Edit and preview

1. Edit project and career content in `content.py`, page templates in `build.py`, or the shared design in `style.css`.
2. Run `python -B build.py` with Python 3.10 or newer to regenerate the English and Arabic HTML.
3. Run `python -m http.server 8000` and open `http://localhost:8000/`.

GitHub Pages serves the checked-in HTML from the repository root.
