# Mahmood Sufyan | Oracle APEX Portfolio

A bilingual, multi-page portfolio for Mahmood Sufyan covering Oracle APEX, PL/SQL, AI application engineering, and Python backend development. It includes six case studies, a career timeline, a contact page, and English/Arabic CV downloads. Golden Cloud includes a 60-second project walkthrough.

OrderMind and Z-STUDIO OS are personal projects conceived and developed from scratch with AI-assisted tools. Shabic is company work. Case studies contain public descriptions only; private source code and company data are not published.

## Edit and preview

1. Edit project and career content in `content.py`, page templates in `build.py`, or the shared design in `style.css`.
2. Run `python -B build.py` with Python 3.10 or newer to regenerate the English and Arabic HTML.
3. Run `python -m http.server 8000` and open `http://localhost:8000/`.

GitHub Pages serves the checked-in HTML from the repository root.
